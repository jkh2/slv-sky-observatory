# Decision 0001: Separate public observatory repository

**Status:** proposed for foundation review

The San Luis Valley Sky Observatory is an independent, public project with its own reporting, evidence, resident Home, and future pod architecture. Eagle Eyes Global remains a separate fork and candidate source of reusable modules.

A separate repository keeps community contributions, issue scope, and case privacy requirements coherent. Selected MIT source may be imported with its copyright and license notices after a dependency and data-rights review. There is no plan to copy bundled datasets wholesale.

The application owns submitted case evidence; a Codex CLI resident on its own VPS works through scoped MCP/API tools. Public data can support the first release; pod hardware is an optional future source.

Revisit this decision if maintenance cost of selected shared components makes a published package or documented upstream contribution preferable.
